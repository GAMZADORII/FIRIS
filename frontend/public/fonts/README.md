# Noto Sans KR

Source: https://github.com/google/fonts/tree/main/ofl/notosanskr
Original: NotoSansKR[wght].ttf, downloaded 2026-10-14.
License: SIL Open Font License 1.1 (see OFL.txt).

The WOFF2 file is a lossless web-font conversion using FontTools,
with the full character set and variable weight range 100?900 preserved.
Digits have equal advance widths by default.
